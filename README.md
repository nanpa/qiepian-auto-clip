一个根据srt字幕自动剪辑视频切片的工具，这是我一个vibe codeing的第一个程序，github也是第一次上传，有许多不懂不完美的地方，请见谅
工作流程为：剪映导出完整的字幕，送入千问等大模型根据需要让AI整理段落，并保留时间戳导出为带时间戳、内容、剪辑建议的MD文档
示例：

| 00:00:08,200 --> 00:00:13,666 | 然后是68块钱 到手是两斤... 川渝地区的话 是第二天都能收到货 | 画面：主播展示手机订单页面，快速剪辑快递分拣中心、冷链运输车出发的画面。<br>叙事意图：体现电商定价的透明化与物流的高效，这是连接深山与城市的关键纽带。 |

| 00:01:47,066 --> 00:01:58,266 | 接下来的话 我们也会继续做好品控... 把更多的原生态好物 推广出去... 助力乡村发展 | 画面：主播眼神坚定地看向镜头，背景是连绵的青山或忙碌的打包现场。<br>叙事意图：升华主题，从单纯的卖货上升到“助力乡村发展”的情怀与责任，展现新农人的担当。 |

| 00:02:58,466 --> 00:03:06,400 | 其实确实真的很辛苦... 就想把我们高山的野菜... 分享给大家 | 画面：镜头切回主播真诚的面部特写，随后拉远，展现人与自然的和谐共生。<br>叙事意图：情感落点。将商业行为回归到人与土地的情感连接，表达让好东西走出大山的朴素愿望。 |

然后复制进软件即可自动根据srt进行剪辑输出
注意：由于ffmpe文件大小限制，需自行下载放入软件目录，下载时注意要下exe文件大于100mb的那个版本
